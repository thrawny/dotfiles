# AeroSpace Notes

`aerospace.toml` is linked to `~/.aerospace.toml`; edits apply without `just switch`. Requires AeroSpace 0.21.3 and Ghostty 1.3 or newer.

After edits run `just test-aerospace` from the repo root. On the Mac, `just check-aerospace` validates with AeroSpace's own parser without applying. Neither exercises AppleScript or real windows, so ask the user to reload (rescue mode, Esc) and smoke-test Alt-Enter and window movement.
